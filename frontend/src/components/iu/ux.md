# Prompt de Diseño UI/UX: Dashboard Académico (StudyFlow) - Versión Corregida y Optimizada

**Rol:** Diseñador de Interfaz Senior (UI/UX) especializado en herramientas de productividad premium.  
**Objetivo:** Generar la imagen de un dashboard web académico ("StudyFlow") ultra-limpio, profesional y moderno, que reemplace la estética genérica por una sofisticada y funcional, conservando estrictamente todos los datos específicos del usuario de la versión original.

---

## 🎨 Instrucciones Generales de Estilo
* **Paleta de Colores:** Neutra y sofisticada. Fondo principal blanco hueso o gris muy claro (`#F8F9FA`). Tarjetas y contenedores en blanco puro (`#FFFFFF`). Textos principales en gris oscuro (`#212529`) y acentos de color sutiles (ej. un verde oliva profesional para elementos activos).
* **Tipografía:** Una sola familia tipográfica sans-serif moderna y geométrica (ej. "Inter" o "Geist"). Uso de pesos variados (Regular, Medium, Semibold) para estructurar la jerarquía visual.
* **Espaciado (Whitespace):** Crucial. Amplio respiro entre contenedores para evitar la saturación visual. Eliminar líneas divisorias innecesarias y usar bordes muy sutiles (`#E0E0E0`) o sombras suaves para elevar las tarjetas.

## 📐 Estructura de la Interfaz (Punto por Punto)

### 1. Barra Lateral (Sidebar - Rediseñada)
* **Fondo:** Un tono gris cálido muy suave que se integre de forma elegante y limpia.
* **Cabecera de Perfil:** Avatar circular minimalista con la inicial "E" y el texto "Estudiante" en peso Medium.
* **Navegación Principal:** Iconos minimalistas de línea fina (tipo Lucide/Phosphor) para las secciones clave:
  * `Inicio` (con fondo de acento sutil y texto en negrita)
  * `Calendario`
  * `Materias`
  * `Configuración`
* **Acción Rápida:** Un botón limpio y destacado en verde oliva para la opción `+ Nueva Tarea`.

### 2. Cabecera Principal (Header)
* **Título:** "Buenos días, Estudiante" (Tamaño grande, peso Semibold).
* **Subtítulo:** "Esto es lo que tienes pendiente hoy." (Peso Regular, gris suave).
* **Acciones Superiores:** Icono de campana sutil para notificaciones y una barra de búsqueda global discreta (con atajo visual `⌘K`).

### 3. Columna Central - "Enfoque Semanal" (Corregido y Limpio)
* **Enfoque Actual:** Una única tarjeta circular grande con el progreso numérico de color sólido ("100") correspondiente a **"PARCIAL 2: DESARROLLO"**.
* **Línea de Tiempo:** Cronología horizontal minimalista para la semana actual (`17`, `18`, `19`, etc.).
* **Gráfico de Carga:** Gráfico de área estilizado en tonos verdes suaves para la carga semanal, con etiquetas limpias en el eje X (`Lun`, `Mar`, `Mié`, `Jue`, `Vie`, `Sáb`, `Dom`).
* **Botones de Acción:** Botones `Comenzar` y `Ver en el tablero` con bordes redondeados y un estilo minimalista.

### 4. Columna Central (Sección Media) - "Resumen de Progreso"
* **Contenedor:** Tarjeta blanca limpia.
* **Estructura de Datos (Conservada):** Listado de materias con barras de progreso lineales y limpias (eliminando los círculos porcentuales repetitivos para reducir el ruido visual):
  * Electiva Python (83% - 20 de sept)
  * Desarrollo (78% - 18 de sept)
  * Inglés Speaking (78% - 18 de sept)
* **Acción:** Botón inferior "Ver todo el progreso >".

### 5. Columna Derecha - "Vencimientos Inminentes" (Reestructurado)
* **Contenedor:** Tarjeta blanca limpia.
* **Título de Sección:** "Vencimientos inminentes".
* **Listado de Tareas (Conservando los datos originales en orden cronológico exacto):**
  * CÁTEDRA - TATEDA 2 (17 de sept)
  * DESARROLLO - TALLER CRITICO (16 de sept)
  * PROGRAMACIÓN - MODULO 11 (19 de sept)
  * CÁTEDRA - TALLER 2 (17 de sept)
  * INGLÉS - SPEAKING (16 de sept)
  * DESARROLLO - TALLER CRITICO (18 de sept)
  * PROGRAMACIÓN - MODULO 11 (19 de sept)
  * DESARROLLO - PARCIAL 2 (19 de sept)
* **Estilo de Ítems:** Uso de tipografía limpia y pequeñas etiquetas de colores pasteles muy discretos para identificar las materias, eliminando por completo los bloques de colores sólidos o semáforos saturados de las versiones anteriores.
